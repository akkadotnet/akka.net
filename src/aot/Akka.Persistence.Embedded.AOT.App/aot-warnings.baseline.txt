# Trim/AOT warning baseline for the SQLite persistence Native AOT canary (src/aot/Akka.Persistence.Embedded.AOT.App).
#
# Same format and checker as the plain-core canary's baseline (src/aot/Akka.AOT.App/aot-warnings.baseline.txt) -
# see that file for the key format and how added/gone entries are handled.
#
# Scope here is three prefixes, comma-separated:
#
#   src/contrib/persistence/Akka.Persistence.Embedded/           - the plugin
#   src/contrib/hosting/Akka.Persistence.Embedded.Hosting/       - the Hosting package the canary is built with
#   src/core/Akka.Streams/                                       - the streams every query runs on
#
# The goal for all three is zero warnings, so this file holds nothing but this header. Warnings from Akka core,
# Akka.Persistence and Microsoft.Data.Sqlite are out of scope: the core canaries baseline their own.
#
# An empty baseline never trips the checker's "measured nothing" guard, so the publish and the run of the app in CI
# are what prove ILC ran and the plugin works.
